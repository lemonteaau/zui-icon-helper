# ZUI 图标助手

给联想 ZUI 平板的**原厂桌面**换图标。不用 root，不用换第三方桌面，壁纸和桌面布局都不动。

<p align="center"><img src="docs/main.png" width="380" alt="主界面"></p>

## 它能做什么

- **导入图标包**：把你装在平板上的图标包（应用商店里买的、免费的、第三方的都行）导入进来，直接用在原厂桌面上。
- **一键换整套**：选一个默认图标包，它收录的应用全部换掉；以后新装的应用也会自动配上。
- **每个应用单独挑**：仿锤子 OS 的「应用图标」设置，原生和替换并排放，点一下就切换；也可以从所有图标包里搜，或者用你自己的图片。
- **统一图标大小**：70%–120% 整体缩放，拖动时就能看到效果。
- **随时还原**：一键恢复出厂图标。

## 适用设备

已在 **联想拯救者平板 Y700 三代（TB321FU，ZUI 17.5，Android 16）** 上测试。

其他运行 ZUI 的联想平板/手机也可能可以用，但没有测试过。助手打开时会自己检查，用不了会直接提示，不会改动任何东西。

## 安装

到 [Releases](../../releases/latest) 下载最新的 `zui-icon-helper-*.apk`，在平板上打开安装即可（如果提示“未知来源”，按提示允许一次）。

## 第一次使用

### 1. 先装一个图标包

助手本身**不带任何图标**（图标都有版权，不能随便打包分发），需要你先在平板上装一个图标包 App：

- **买过的图标包**：直接从应用商店装上就行。
- **第三方图标包**：拿到 APK 后安装即可。只要是支持 Nova、ADW 等桌面的通用图标包都可以。
- **还没有图标包？** 可以先试试免费的 [CraftEcho Icons](https://github.com/gaodeng/CraftEcho-Icons/releases/latest)（锤子风格，下载那个 `.apk` 安装）。

> 图标包 App 装上后不用打开它，也不用设置它，回到助手导入就好。

### 2. 在助手里导入

打开「ZUI 图标助手」→ 点 **图标包** → 在“平板上可导入的图标包”里点 **导入**。

图标多的包（上千个）需要一两分钟，导入时别离开助手。导入完成后，图标包 App 卸不卸载都不影响已经导入的内容（想以后更新就留着）。

<p align="center"><img src="docs/packs.png" width="380" alt="图标包管理"></p>

### 3. 选默认图标包，然后应用

点 **默认图标包**，选刚才导入的那一个，再点底部的 **应用选择**。几秒钟后桌面图标就换好了。

## 单独换某个应用的图标

界面参考锤子 OS 的「应用图标」设置：每个应用一行，左边是原生图标，右边是替换图标，**红色小勾**标着正在用的那个。

- 点右边的图标就换上，点左边的就用回原生。
- 默认图标包没收录的应用，右边是一个 **＋**，点它（或点那一行）去挑。
- 点进任意一行是「替换图标」页：上面是这个应用，下面依次是它在各个图标包里的样子、你导入过的图片，还可以在所有图标包里搜索（中文、英文、包名都行）。
- 在「我的图片」里点 **＋**，可以用你自己的图片：拖动、缩放、旋转调整好，透明背景会保留。
- 想回到跟随默认图标包，就在详情页里选默认图标包里的那一个。

选完记得点底部的 **应用选择**，桌面才会变。

## 统一调整图标大小

主界面点 **图标大小**，拖动滑块（70%–120%），上方会实时显示你自己的几个图标缩放后的样子。点「确定」，再点底部的 **应用选择**。100% 保持素材原样；缩小会增加透明留白，放大超出原画布的部分会裁切。不会改变桌面格子、排列或文字大小。默认包里的图标、单独指定及自定义图片使用同一比例；之后安装的应用，只要默认包已收录，也会使用该比例。

未被主题替换的图标，以及桌面自己绘制的动态图标，不受此设置影响。「撤销修改」会同时撤销大小调整；恢复系统原始图标会重置为 100%。

## 恢复原样

右上角 **设置 → 恢复系统原始图标**。会回到当前主题出厂时的图标，壁纸和布局不变。

## 常见问题

**为什么不直接自带一些图标？**
图标包的图片属于原作者，随便打包分发会侵权。所以助手只负责“导入你自己装的图标包”，图片只在你的平板上转换使用，不会上传到任何地方。

**日历和时钟的图标换不掉？**
ZUI 的原厂桌面会把 Google 日历、Google 时钟显示成动态图标（显示当天日期、走动的指针），这两个是桌面直接画的，主题换不了。

**浏览器“添加到主屏幕”的网页快捷方式换不掉？**
那种是快捷方式，不是应用，系统主题管不到它。

**在系统设置里换了主题之后，图标变回去了？**
换主题会重置图标。回到助手点一次 **应用选择** 就好。

**会不会把系统改坏？**
助手只替换当前主题里的图标文件。应用时如果出了问题，会自动退回之前的状态；任何时候都能一键恢复原始图标。如果平板上有多个用户，图标的变化可能对其他用户也生效。

**某个应用在图标包里明明有，却没换上？**
少数系统应用会和别的应用共用同一张图标，ZUI 不允许它们分开设置，助手会提示。另外图标包的作者可能没收录这个应用，可以用“更多图标”手动挑一个。

### 发布签名

发布工作流使用 GitHub Actions Secrets：`KEYSTORE_BASE64`、`KEYSTORE_PASSWORD`、`KEY_ALIAS`。本地无需保存发布私钥。工作流只在临时目录还原密钥，并在退出时清理；发布前核对签名证书指纹，保证已有用户可以覆盖升级。

另存的 `PERSONAL_KEYSTORE_BASE64`、`PERSONAL_KEYSTORE_PASSWORD`、`PERSONAL_KEY_ALIAS` 属于自用版的独立身份。云端只做临时签名验证，不发布带自用版签名的公开 APK。自用版素材不在此仓库中。
